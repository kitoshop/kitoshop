KITO Website V13 — Vietnamese default

1. Extract ZIP.
2. Upload ALL contents of this folder (not the outer folder) to the GitHub Pages publishing root.
3. GitHub Pages: Settings > Pages > Deploy from a branch; select the branch and /(root).
4. The root index.html serves Vietnamese immediately. /en/, /zh/, /ja/, /fr/, /ru/ are localized pages. /vi/ also works.
5. Custom domain: kitoshop.vn; verify DNS and Enforce HTTPS.
6. Changes may take time to propagate.

The ZIP is a deployment archive; do not upload the ZIP itself to the repository.
